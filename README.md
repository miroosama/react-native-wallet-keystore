# react-native-wallet-keystore

Hardware-protected wallet key storage with authenticated signing for React Native

## Installation


```sh
npm install react-native-wallet-keystore
```


## Usage


```js
import { multiply } from 'react-native-wallet-keystore';

// ...

const result = multiply(3, 7);
```
